## 设计方向

沿用 Codex 的界面习惯：系统无衬线字体、紧凑工具栏、细分隔线、低对比容器、中性色主按钮。模型内容是视觉中心，不使用营销式大标题或强渐变。

- 浅色：画布 #FFFFFF，侧栏 #F7F7F8，文字 #242426，边框 #E5E5E7。
- 深色：画布 #212123，侧栏 #19191B，文字 #ECECEE，边框 #39393D。
- 状态绿：浅色 #24684F / 深色 #91C8AD，仅用于状态，不作为大面积装饰。
- 字体：标题、正文使用系统 UI 字体；模型数值与视口标识使用系统等宽字体。
- 布局：完整工作台使用 204px 导航 + 主预览 + 290px 操作面板；小屏合并为上下布局。
- 标志性区域：大模型视口与紧邻的处理参数，让“查看结果”和“继续处理”在同一处完成。

原型导航属于插件自己的工作区，并非宣称已经注册 Codex 原生侧栏。正式嵌入窄面板时省略内部侧栏，避免与 Codex 导航重复。

## 主题与可访问性

提供跟随系统、浅色、深色三种模式；选择保存在本地。正式集成时默认跟随宿主提供的主题与设计变量，独立浏览器模式跟随系统。同步主题切换，不重新创建任务或丢失表单。

状态配合文字，不仅使用颜色；交互提供键盘焦点；弹窗支持 Escape；尊重减少动态效果偏好。正式版还需验证宿主主题变量映射、WCAG AA 对比度、WebGL 模型可见性与键盘/读屏操作。

## 本轮可以操作

主题切换、工作台/资产库/任务中心导航、资产搜索与选择、材质/线框示意切换、重拓扑面数与拓扑类型选择、操作切换、任务确认和模拟排队。

创建模型与登录按钮显示说明弹窗，完整创建向导、登录状态页、真实模型旋转缩放、下载与失败状态页面在后续实现。本稿不把这些占位入口算作功能完成。
