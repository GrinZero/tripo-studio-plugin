# 工作台详情页布局修复 · 2026-10-09

详情页的处理页签使用不可换行文字和固定内边距，超过面板宽度；3D 预览使用固定最小高度和宽高比，宽窗口下会把整页撑高。Smart Poly 开关还继承了普通输入框的最小高度。

本次修改：

- 处理页签改为等宽网格，允许中英文换行；长模型名显示省略号，悬停可查看完整名称，长部件名允许换行。
- 详情页按 MCP 宿主的 `containerDimensions.height` / `maxHeight` 约束高度，没有尺寸信息时使用 `100dvh`。预览填充剩余高度，画布继续使用原有 ResizeObserver 更新尺寸。
- 缩小面板间距与控件高度，把报价刷新按钮移到费用标题行，历史记录收为可展开区域。
- 桌面详情页不再产生外层滚动条；窗口较矮或部件较多时，处理面板内部滚动。960px 及以下使用单列，主内容区域滚动，确保所有控件可访问。
- 开关固定为 40 × 22px，不再继承普通输入框的内边距和最小高度。

验证：`npm run build` 通过；`npm test` 106 项通过。使用模拟 MCP 宿主和有效 GLB 进行浏览器检查，没有调用 Studio 或提交付费操作。

`test/browser/check-workbench-layout.js` 覆盖简体中文、繁体中文、英文和日文，在 1560×820、1280×720、1024×600、960×720、680×720、390×844、320×640 下检查页签边界、横向溢出、页面高度、开关尺寸、画布缩放和底部按钮可达性；另检查宿主高度变化、历史展开、超长名称、语言切换后参数保留、三种处理操作与导出弹窗。正常内容在 1560×820 下处理面板无需滚动。

运行浏览器检查：先启动 `node test/browser/i18n-server.mjs`，再执行 `playwright-cli run-code --filename test/browser/check-workbench-layout.js`。截图保存在 `output/playwright/detail-layout-*.png`。

工作台运行时读取 `ui/workbench.html` 与 `dist/workbench.js`。已打开的页面需要重新打开，才能加载更新。
