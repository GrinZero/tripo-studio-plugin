# 资产分组卡片与直接多选

资产页的模型和图片都支持直接点击卡片累加选择，再次点击取消。不需要先开启“多选”模式；“查看详情”是独立入口。选择跨页保留，可创建分组、加入已有分组，或在组内移出分组。

根目录只显示分组卡片和未分组资产。组内成员不重复出现在根目录。分组卡片使用成员预览拼图、名称和完整数量；点击进入成员页，每页 20 项。服务端先读取完整账号资产目录，再聚合、搜索、排序和分页；数量不取当前页长度。

手动归属保存在数据目录的 `asset-groups.json`，按账号隔离，通过文件锁同步。显式移出分组保存 null 覆盖，避免旧任务角色归属重新出现；空组不占据根目录卡片。自动角色归属仍来自当前账号最多 5000 条保留任务的真实输出 ID。手动分组不改变 Studio 项目、任务参数或收费请求。

新增 app-only `tripo_ui_asset_library`，提供 list/assign。当前合计 67 个工具，其中 4 个为界面专用工具；另提供 5 个公开的 [agent 分组管理工具](ASSET_GROUP_TOOLS_2026-10-09.md)，与工作台共用归属和名称。

验证：113 项自动化测试全部通过，覆盖整库聚合、组内分页、持久化、账号隔离、图片加入模型分组、移出与并发写入。Computer Use 使用原生 Safari 实际连续点击卡片、跨页选择、创建分组、打开成员页；发现并修正了普通卡片额外空白导致底边不齐、选中悬停边框不一致、组导航滚动位置未复位和弹窗字段间距。另检查 420/320 px 响应式视口的多选操作栏。

Computer Use 实拍截图在 `output/computer-use/`：`asset-group-root.png`、`asset-direct-multiselect.png`、`asset-create-group.png`、`asset-group-members.png`、`asset-multiselect-420.png`、`asset-multiselect-320.png`。验收页使用真实分组服务与本地持久化、模拟 Studio 目录及预览；不会修改用户的真实资产。

源码与构建产物同步到本机插件前先备份。宿主需要重新加载插件连接并重新打开工作台，才能发现新界面工具。尝试原生 Codex 验收时，Computer Use 返回该应用被安全策略禁止控制；未将 Safari 隔离验收结果声称为原生 Codex 验收。
