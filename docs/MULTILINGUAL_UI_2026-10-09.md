# 多语言界面

工作台、配置卡片、结果卡片及报价卡片支持简体中文（`zh-CN`）、繁體中文（`zh-TW`）、English（`en`）和日本語（`ja`）。页面顶部的语言选择器可随时切换。

## 语言选择

默认“跟随宿主 / 浏览器”的优先级是宿主 MCP Apps context 的 `locale`、浏览器 `navigator.languages`、英文。手动选择优先于自动识别，写入 `localStorage` 的 `tripo.language`，同源已打开页面通过 `storage` 事件同步。宿主没有提供 `locale` 时仍可使用浏览器偏好；存储受限时仍可切换，但不会记忆选择。

`zh-Hans`、`zh-CN`、`zh-SG` 对应简体，`zh-Hant`、`zh-TW`、`zh-HK`、`zh-MO` 对应繁体。明确指定脚本时优先使用脚本，例如 `zh-Hans-TW` 使用简体。英语和日语地区变体分别归为 `en`、`ja`。

## 实现

- `ui/i18n.mjs` 提供语言解析、插值、日期与数字格式化、语言选择器，以及文案和无障碍属性的更新。
- `ui/locales/*.mjs` 包含四份完整字典，以简体源文案为键。新增语言时添加字典文件并在 `catalogs`、`languages` 注册；保持插值占位符一致。
- 工作台在重绘前捕获当前输入；配置卡片就地更新文案，保留控件节点、参考图、编辑状态、请求中的保存和既有倒计时。
- 弹窗在语言变化时保留本次导出选项与费用确认勾选。打开新的确认弹窗时重新获取本次同意，不继承上一次勾选。
- 用户填写的提示词、角色名、模型名、文件路径以及后端返回的原始内容保持原值。只翻译明确标记的界面文案；生成提示词预设随界面语言显示。
- MCP 工具名、协议状态、参数值和持久任务不随界面语言修改。语言切换不会保存、重新暂存或提交任务。

字典经 esbuild 打包到现有工作台与卡片脚本，不需要额外的网络请求或运行时依赖。

## 验证

```bash
npm run build
npm test
```

`test/i18n.test.mjs` 验证语言优先级、脚本/地区变体、字典覆盖、占位符一致性、用户值插值、格式化和未知文案回退。

实际浏览器验证使用模拟 MCP 宿主，无 Studio 请求或计费。安装 Python Playwright 和 Chromium 后执行：

```bash
node test/browser/i18n-server.mjs
# 在另一终端运行
python3 test/browser/check-i18n.py
```

验证覆盖四种语言、记忆与同源同步、宿主语言变化、存储受限、输入和参考图保留、自动提交期限不变、保存过程中切换、费用确认和导出弹窗、28 项功能目录、报价和窄屏布局。截图保存在 `output/playwright/*-ja*.png`。
