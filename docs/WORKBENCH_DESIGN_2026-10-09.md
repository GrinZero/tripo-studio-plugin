# 工作台 UI 优化 · 2026-10-09

面向管理、预览和继续处理 3D 资产的创作者。界面的首要任务是快速找到资产并进入下一步处理。

## 设计方向

采用「3D 样本架」：冷静的蓝灰工作区、陶橙操作色，以及模型预览的坐标角标。保留横向导航，适应 Codex 面板与完整窗口；不加入营销式大标题或占用空间的侧栏。

色彩：雾蓝 #F1F4F7、瓷白 #FFFFFF、深板岩 #19232D、展台蓝 #253442、陶橙 #AD573F、浅陶橙 #DE9476。标题使用 Avenir Next Condensed，正文使用 Avenir Next / PingFang SC，数量和数据使用 SFMono-Regular；均提供系统字体回退，无外部字体请求。

布局：导航 → 标题与创建操作 → 搜索筛选 → 资产网格 → 分页；选择后出现固定操作条。特色集中在模型展台的取景角标，避免额外装饰影响浏览。

## 实现

- 统一资产、任务、创建、详情与确认对话框的排版、表面、边界和控件尺寸。
- 资产网格按可用宽度自适应；手机双列、详情与创建设置单列。
- 图片绝对定位在固定比例容器内，防止缩略图固有高度撑开网格。
- 显式选中状态与辅助技术状态，重复点击取消选择，并提供取消选择按钮。
- 空搜索结果支持清除搜索；明确搜索与排序仅作用于当前页。
- 保留键盘焦点提示、减少动态效果偏好与系统/浅色/深色主题。

## 验证

`npm run build` 通过，`npm test` 90 项全部通过。
浏览器检查资产选择、取消选择、清空搜索、桌面深浅主题、390px 资产和创建页面。窄屏 documentElement.scrollWidth 等于 innerWidth（390），无横向溢出。
