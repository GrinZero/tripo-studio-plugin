# Tripo 工作台 0.3.0

本轮依据 [模块设计稿](../design/concepts/modules-v1.md) 实现四个页面：资产总览、模型详情、任务列表与详情、创建模型。插件只绘制工作台自身；宿主侧栏和聊天区域由 Codex 提供。

## 已实现

- 资产：真实模型／图片缩略图、模型类型筛选、当前页搜索、按创建时间或名称排序、网格／列表、实际后续页、选择、详情与下载。
- 模型详情：GLB 旋转缩放、重置视角、材质／线框、从实际网格计算的三角面数、真实分件；重拓扑、文字贴图、Rig V3 和可配置导出。内部生成的分件名在界面显示为“部件 N”，提交仍使用原始名。
- 任务：按状态组分页、输出预览、冻结参数、真实事件、输入快照及哈希、上游任务引用、下载路径；仅待提交草稿可取消。当前选中的活动任务在页面可见时每 10 秒刷新。
- 创建：本地图片选择／拖入、文字描述、多视图固定视角，H3.1 与 Smart Mesh P2 配置；只发送当前模式支持的参数；本地图片先保存到素材目录。图片生成不展示工具不使用的补充描述框。
- 报价与提交：参数变更使旧报价失效。生成按钮需要完整输入和有效报价；保存草稿与冻结参数确认分离。提交使用实际 task_id、confirmation 和 request_hash。未知费用操作在确认弹窗明确显示，不伪装成免费。未知提交结果不自动重试。
- 主题：跟随宿主／系统、浅色、深色；主题切换保留表单。680 px 以下把工作区与参数列合并为上下布局，420 px 已验收。

## 媒体与宿主

两个工作台专用工具只声明 `ui.visibility:[app]`，不改变 55 个模型工具与 28 种操作：

- `tripo_ui_preview`：从真实项目、图片、任务或本地导入句柄读取缩略图／预览。签名 URL 留在服务端，图片缩放为 WebP，预览字节仅出现在 `_meta.tripo.preview` 中。限制图片 20 MiB、模型 32 MiB；拒绝不允许的域名、每一次不安全重定向及外部 GLB 资源。服务端解码 Studio 的 meshopt，浏览器不依赖外部 CDN 或 WebAssembly 权限。模型预览同时提供原始分件名，避免界面为读取分件重复下载大模型。超过限制或缺少 WebGL 时显示原因，仍可下载文件。
- `tripo_ui_import_image`：只接受用户选择的 PNG/JPG/WebP，规范化保存至配置素材根目录 `ui-inputs`，返回随机句柄、素材路径和预览；不上传至 Studio、不创建付费任务。

标准 MCP Apps SDK 初始化、global/thread 入口、MIME 与 CSP 沿用已注册协议。界面不需要自建常驻 Web 服务，也不嵌入 Studio 官网。

## 验证

构建与测试通过；新增验证覆盖参数互斥、输入校验、报价到期、分组分页、媒体字节上限、重定向校验、外部 GLB 资源拒绝，以及分发包中 app-only 工具的可见性和媒体元数据。

本机临时标准 AppBridge 宿主使用真实账号只读资产，任务和输入使用隔离目录，付费提交已禁用。已确认：

- 真实 54 个模型的缩略图与第二页读取。
- Studio 压缩 GLB 正确解码，真实模型视口显示 4,467 triangles，线框可切换。
- H3.1 标准几何／4K／PBR 的报价为 40；改为精细几何后变为 55，旧报价期间生成按钮禁用。
- 文字生成冻结参数弹窗、草稿记录与取消；未发送付费请求。
- PNG 选择及本地导入、多视图缺少其他视角时禁用、Smart Mesh 不发送高精度贴图选项；420 px 与浅／深色显示。
- 嵌入 GLB 图片通过 `TextureLoader` 加载；在 `connect-src 'none'`、仅允许 `img-src data: blob:` 的验证页面中，贴图实际渲染成功。

实际界面截图保存在本机 `.local/verification/workbench-v3/`：`assets-dark.png`、`detail-dark.png`、`tasks-dark.png`、`create-dark.png`；均来自实际工作台运行页面。

浏览器验收证明工作台界面和标准协议运行，不等同于 Codex 原生侧栏可见性验收；原生侧栏仍需要宿主重新加载插件并观察实际入口。测试没有执行付费生成、重拓扑、贴图或绑定。
