# Plugin updates

For every update to this plugin, including features, fixes, UI, skills, and documentation, run `pnpm run build` to refresh the workbench version marker and include the generated distribution files with the change. The marker must use `v<package.json version>-YYYYMMDDHHmmss` with a build timestamp in `Asia/Taipei`; do not generate a timestamp when the page opens. Run `pnpm run check:distribution` after building to verify the marker matches the packaged workbench. Keep the base version synchronized through the existing `version` lifecycle when releasing a new package version (`pnpm version`).

Use the pnpm version pinned in `package.json` and commit `pnpm-lock.yaml`; do not create an npm or Yarn lockfile. Before committing, run `pnpm run check` and `pnpm test`. Husky runs lint-staged, tests, distribution validation and Conventional Commits validation. Generated distribution files, fixtures and third-party license texts are excluded from format/lint fixes. A package-manager or release change must also pass `pnpm run test:package`.
